📚 Atividade em Grupo — Desenvolvimento de Site com CI/CD

Tema: Letterbox de música 

🎓 Disciplina: Programação Frontend e DevOps 

🎯 Objetivo

Desenvolver um projeto prático que integre conceitos de desenvolvimento frontend  e boas práticas de DevOps , utilizando versionamento, integração contínua e entrega contínua.

 👥 Formação dos Grupos
- Cada grupo deverá escolher um tema relacionado à sua convivência , como por exemplo:
- cotidiano universitário
- hobbies
- tecnologia
- esportes
- cultura, entre outros

 💻 Requisitos do Projeto
O grupo deverá desenvolver um **site funcional** utilizando obrigatoriamente:
- ✅ HTML
- ✅ CSS
- ⚠️ JavaScript (opcional, mas recomendado)
- ✅ Framework CSS (ex: Bootstrap, Materialize, Foundation ou similares)
- ✅ Testes End-to-End (E2E) utilizando Cypress 

 🔐 Versionamento
O projeto deverá ser hospedado em um repositório privado no GitHub , contendo:
- Apenas os membros do grupo e o professor como colaboradores
- Organização clara do código
- Histórico consistente de desenvolvimento

 📊 Critérios de Avaliação no GitHub
  🔄 Versionamento e Colaboração
- Histórico de commits 
- Participação dos membros (autoria dos commits)
- Frequência das contribuições

   🌿 Estratégia de Branches
- Criação de branches específicas  para desenvolvimento de funcionalidades

   🔀 Integração de Código
- Uso de Pull Requests 
- Realização de merges  organizados

 📄 Documentação (README.md)

O repositório deverá conter um arquivo README.md  com, no mínimo:
- 📌 Descrição do projeto
- 🌐 Link/endpoint do site funcional

 ⚙️ DevOps — CI/CD
- ✅ Pipeline de CI (Integração Contínua) 
- ✅ Pipeline de CD (Entrega Contínua) 
> Deverá obrigatóriamente utilizar GitHub Actions 

 🚀 Apresentação
- O grupo deverá demonstrar o funcionamento do site
- Será solicitado que alterações no código sejam realizadas ao vivo 
- Espera-se que o pipeline execute e o resultado seja refletido em tempo real no site

 📦 Entrega
- 🔗 Link do repositório privado no GitHub

📝 Observações Importantes
- Projetos sem pipeline funcional terão desconto na nota
- Falta de participação individual pode impactar a avaliação geral do grupo
